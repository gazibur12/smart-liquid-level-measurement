01 / PROJECT OVERVIEW

From distance to liquid level.

The sensor measures the air gap between its face and the liquid surface. The controller uses that distance to estimate how much of the container is filled.

⌁
THE IDEA

Measure without contact

The HC-SR04 sends an ultrasonic pulse and measures the time taken for the echo to return from the liquid surface.

01 ULTRASONIC DISTANCE
⌗
THE CALCULATION

Convert distance to level

Liquid height is calculated by subtracting the measured air gap from the known container height.

Liquid level = 9.2 cm − air gap

THE OUTPUT

Display useful information

The OLED shows liquid height and estimated fill percentage. LEDs provide a quick visual indication of the level.

06 / PROJECT LOGIC

Simple logic.
Clear feedback.

The controller converts the measured distance into a liquid height and percentage, then selects the LED based on the fill thresholds.

Try the interactive demo ↗
level_logic.ino
liquidLevel = containerHeight - distance;
fillPercentage =
  (liquidLevel / containerHeight) * 100.0;

if (fillPercentage >= 75) {
  greenLED = HIGH;
} else if (fillPercentage >= 30) {
  yellowLED = HIGH;
} else {
  redLED = HIGH;
}
